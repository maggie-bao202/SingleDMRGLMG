This package was developed for **[Benchmarking Quantum and Classical Simulations of the Lipkin-Meshkov-Glick Model](https://github.com/Quantum-Solutions-Launchpad/LMG-Model-Quantum-Benchmarking-with-Tensor-Networks/tree/main)** and is discussed in the associated [arXiv manuscript](https://arxiv.org/abs/2607.28570). It provides the single-run DMRG implementation used in the benchmarking workflow.
This package was also precompiled into a custom Julia **system image (sysimage)** to reduce Julia startup and JIT compilation overtime. A CPU execution path—and a GPU execution path when CUDA is available—is ran as a warmup during precompilation so that commonly used DMRG code is compiled ahead of time.
